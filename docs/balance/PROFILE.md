# 특성 재설계 평가 · 2026-10-16

## v0.12.1 성장 목표 변경

사용자 요청에 따라 서로 다른 전설 6개 장착을 약 50분의 장기 목표로 변경했다. 분당 보상 1.6회라는 기존 환산 가정을 유지해 조정 효과만 비교한다. 임의로 시간 배율을 높이지 않으며, 실제 플레이 시간 검증과는 분리한다.

수급 조정은 기본/상급 재료 선택에 한정한다. 3·4티어 직접 지급과 전투력 상향은 사용하지 않는다. 중후반 상급 보상 확률 증가, 이미 보유한 특성과 조합할 수 있는 선택지 보정으로 막히는 구간을 줄인다. 같은 시드·같은 선택 정책으로 이전 수급과 비교하고, 보정에 쓰지 않은 별도 64개 시드로 확인한다. 전체 표본의 중앙 도달 시간과 상한 미완성 수를 함께 보고하여 완성한 표본만의 중앙값 편향을 피한다. 실제 플레이의 보상 속도가 확인되기 전까지 환산 시간은 확정된 플레이 타임으로 표현하지 않는다.

## 판단 목표

이동 → 직접 공격 → 처치 연쇄 → 적 턴 → 보스 보상 → 특성 조합의 흐름을 유지한다. 1티어는 약한 재료이면서 작은 전술적 이점을 주고, 상위 티어는 원재료 효과의 단순 합과 다른 발동 조건·공격 패턴을 가져야 한다.

## 가설과 수정 기준

- 1티어는 빈칸 착지만으로 적을 죽이거나 턴을 무한 연장하지 않는다. 직접 처치 후 보조 타격은 최대 한 대상이다. 실패하면 발동 조건과 대상 수를 수정한다.
- 상위 특성은 짝수 이동에 일괄 발동하지 않는다. 직접 처치, 이동 거리, 연속 처치, 적 턴 기준 재사용 대기시간으로 구분한다. 같은 티어 내 완전히 동일한 규칙이 있으면 다시 설계한다.
- 내구도만 깎아서는 특성 보너스 XP를 얻지 못한다. 처치 없는 반복 타격으로 성장하면 수정한다.
- 같은 효과는 중복 장착으로 중첩되지 않는다. 화면 밖 무제한 관통과 보스 기믹 무시는 허용하지 않는다.
- 동일 보드·기물·입력에서 기존 대비 1티어의 평균 보조 피해가 낮아져야 한다. 상위 티어는 조건을 맞추면 1티어보다 많은 보조 타격을 줄 수 있어야 한다. 개별 조건형 특성은 모든 보드에서 우월할 필요가 없다.

## 증거와 한계

전투 평가는 고정 시드로 생성한 보드와 실제 `game.js`의 이동/공격 함수를 사용한다. 보드·기물·입력·빌드를 단위로 피해, 처치, XP, 턴 유지와 이동 가능 수를 기록한다. 초기 상태가 같지 않은 장기 오토 플레이 결과는 인과 비교로 취급하지 않는다.

성장 속도는 별도 모델로 다룬다. 보상 획득 주기·보스 도구 회수·선택 정책·슬롯 제약을 명시하며, 가정한 시간표가 실제 플레이 시간이라는 주장을 하지 않는다. 15분에 전설 6개를 얻는 목표의 달성 여부는 결과로 공개한다.

각 원시 결과·요약에는 시드, 실행 규칙 해시, 작업 트리 상태와 표본 수를 남긴다. 실제 유저의 재미, 모바일 조작과 체감 난도는 이 시뮬레이션으로 판정하지 않는다.
