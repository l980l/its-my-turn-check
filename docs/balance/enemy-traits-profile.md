# 적 특성 초기 밸런스 프로필

갱신일: 2026-10-20 (v0.15.2)  
상태: 초기 도입값 — 실제 플레이 데이터로 조정 예정

## 등장 확률

v0.15.1부터 웨이브가 아닌 실제 플레이 시간에 따라 새 일반 적의 특성 확률을 정한다. 아래 기준점 사이에서는 선형 보간하며 30분 이후 기본 확률은 40%로 유지한다. 첫 3턴은 시간과 무관하게 특성 생성을 막는다.

| 플레이 시간 | 기본 등장 확률 | 위험 계약 중 |
| --- | ---: | ---: |
| 0–1분 | 0% | 0% |
| 2분 | 6% | 12% |
| 5분 | 10% | 20% |
| 10분 | 16% | 32% |
| 20분 | 28% | 56% |
| 30분 이상 | 40% | 80% |

위 확률은 적 한 기가 생성될 때의 독립 확률이다. 특성 적 수에 별도 하드캡은 두지 않는다. 다만 일반 웨이브 생성량, 보스, 지형 때문에 실제 화면 위 동시 수는 플레이 상황에 따라 달라진다.

플레이어/적 턴의 실제 초만 누적한다. 업그레이드·계약·개발자 선택·사망·메뉴와 숨겨진 탭 시간은 제외한다. 프레임 애니메이션 dt 상한과 개발자 배속은 이 시계를 바꾸지 않는다. 개발자 +5분 도구로만 명시적으로 시간을 건너뛸 수 있다. 시간에 따른 난이도이므로 조작 없이 고민하는 플레이어 턴도 누적된다.

## 복수 특성

v0.15.2에서는 연속 조건부 추첨을 제거하고, 특성 적으로 선택된 경우 보유 개수를 한 번 추첨한다. 분모는 특성 적이며 30분 전에는 모두 1특성이다.

| 플레이 시간 | 1개 | 2개 | 3개 | 4개 |
| --- | ---: | ---: | ---: | ---: |
| 30분 | 95% | 5% | 0% | 0% |
| 40분 | 80% | 20% | 0% | 0% |
| 45분 | 65% | 30% | 5% | 0% |
| 60분 | 30% | 40% | 25% | 5% |
| 75분 이상 | 15% | 40% | 30% | 15% |

각 기준점 사이의 네 가중치를 선형 보간하므로 합은 항상 1이다. 40~45분에 3개가 0→5%, 45~60분에 4개가 0→5%로 증가한다. 75분 이후에는 마지막 비율을 유지한다. 선택한 개수만큼 ID를 중복 없이 뽑는다.

전체 신규 일반 적 기준으로 30분의 2특성은 2%(40%×5%), 60분의 3특성은 10%, 4특성은 2%, 75분의 4특성은 6%다. 계약 중에는 이 확률들이 각각 2배지만 특성 적 내부의 보유 개수 비율은 변하지 않는다. 이 값은 규칙에 따른 계산이며 실제 생존 난이도나 재미를 입증하지 않는다. 복수 특성이 한 적에서 동시에 동작하며, 분열 자식은 남은 분열만 계승한다(계약 보상 자격은 유지).

검증 기준: 모든 기준점과 구간 중간값의 네 비율, 7초 간격의 0~90분 합계/범위, 계약 유무에 따른 개수 추첨 일치, 30분 전 단일 특성, 중복 없는 1~4개 선택을 검사한다. 고정 시드 20261019의 60분 생성 120,000회에서 전체 생성 분모의 기대 비율 [무특성 60%, 1개 12%, 2개 16%, 3개 10%, 4개 2%]와 각 비율 오차 0.6%p 이내인지 확인한다. 이는 추첨 구현 검사이며 전투 시뮬레이션이 아니다. 실패하면 확률/보간 구현을 수정하고, 생존 난이도에 관한 판단은 실제 플레이 후 별도로 한다.

## 네 가지 적 특성

| 특성 | 위협 | 핵심 대응 | 초기 의도 |
| --- | --- | --- | --- |
| 수호 | 인접 8칸의 다른 일반 적을 특성·시너지 공격에서 보호 | 수호자를 직접 처치한 뒤 광역 공격 | 강한 특성 빌드에도 처치 순서를 만든다. 수호자 자신과 보스는 보호 대상이 아니다. |
| 잔불 | 처치된 칸이 다음 적 턴에 폭발 | 처치 체인으로 해당 칸을 벗어나기 | ‘잡으면 한 번 더 움직인다’는 핵심 규칙을 동선 판단으로 확장한다. |
| 치유 | 적 턴마다 주변 2칸의 손상된 일반 적 하나를 1 회복 | 한 대상을 끝까지 처치하거나 치유사를 먼저 제거 | 내구도가 있는 적을 무한 회복시키지 않으며, 한 적은 한 적 턴에 최대 1만 회복한다. |
| 분열 | 처치되면 최대 두 단계까지 폰으로 최대 2기 분열 | 분열 위치를 체인 발판으로 활용하거나 빠르게 정리 | 원본 → 최대 2기 → 최대 4기까지만 이어진다. 마지막 세대는 다시 분열하지 않는다. |

수호는 특성 공격만 막는다. 플레이어가 적 칸으로 직접 이동하는 공격과 아이템 공격은 막지 않는다. 잔불은 플레이어의 연속 행동 중에는 폭발하지 않으며, 다음 적 턴에만 판정한다.

## 위험 계약

위험 계약은 10회의 적 턴 동안 유지된다. 기존 보상은 유지한다.

- 계약 중 생성된 적: XP 2배, 점수 1.5배
- 변경된 패널티: 특성 적 등장 확률 2배
- 제거된 패널티: 적 내구도 +1

내구도를 올리는 방식은 플레이어 턴이 처치 뒤에도 유지되는 구조에서 체감 위협이 약했다. 대신 특성 적 밀도를 높여 우선순위와 이동 경로를 더 자주 바꾸도록 한다.

## 시각 구분 원칙

내구도는 기존 무지개색으로 표현하므로, 적 특성은 색만으로 식별하지 않는다. 기물의 우상단에 큰 원형 배지를 사용한다.

- 수호: 청록 방패
- 잔불: 주황 불꽃
- 치유: 초록 십자
- 분열: 보라 가지

수호받는 적은 별도의 작은 방패 윤곽으로 보조 표시한다. 배지는 화면 밖 적 경고에도 유지해야 하며, 우하단의 기존 위험 계약 마름모 표시는 제거한다.

## 검증 범위와 미검증 항목

v0.15.1 복수 배지 재검사: 위 세 해상도에서 2·2·3·4특성 적을 놓고 배지 원형 외곽 사이의 비겹침을 확인했다. 각 해상도에서 모든 배지를 실제 포인터 입력으로 눌렀으며 총 33/33회 전체 특성 설명이 열리고 플레이어 좌표/턴이 보존됐다. 설명창 가로 넘침과 브라우저 예외는 0건이었다. 화면 밖 4배지 배치도 좌표로 비겹침을 확인했다. 단일·최적화 렌더 경로를 모두 호출했으며 모바일 스크린샷을 검토했다. 이 검사는 합성 픽스처를 사용한 로컬 Chrome 검사로 실제 아이폰 성능이나 손가락 사용성 검증은 아니다.

UI 초기 검사(2026-10-19): 별도 로컬 픽스처와 Chrome headless로 320×568, 390×844, 1440×900의 보드·적 특성 튜토리얼·계약창을 확인했다. 9개 화면 상태에서 브라우저 예외 0건이며, 각 해상도에서 실제 포인터 입력으로 배지 설명을 열어도 플레이어 좌표와 턴이 유지됨을 확인했다(3/3). 보드 배지는 각각 약 20·21.12·33.44 CSS px로, 그림과 색을 함께 사용한다. 보드 배지의 설명 터치 영역은 지름 최소 24 CSS px다. 모바일 튜토리얼/계약창 가로 넘침이나 화면 밖 패널은 관찰하지 않았다. 스크린샷 검토 중 발견한 튜토리얼 캔버스 위치와 분열 가지 경로를 수정하고 재검사했다. 실제 iPhone의 성능·손가락 조작감·색각별 식별성은 미검증이다.

20개 고정 시드의 인위적 준비 상태(높은 레벨과 긴 초기 무적 유예)를 이용한 추가 연동 스모크에서 총 740회 플레이어 행동/적 턴을 실행했다. 8개는 보스에게 잡혀 종료했고 12개는 40턴 제한에 도달했다. 종료 전 활성 보드에 겹친 적이나 런타임 예외는 없었다. 이 과정에서 기존 나이트가 보스 칸에 착지할 수 있는 문제를 수정하고 회귀 테스트를 추가했다. 생존율이나 난이도 평가로 해석하지 않는다.

`scripts/test-enemy-traits.cjs`는 확률 경계, 순수 규칙, 보호·치유·분열의 기하를 확인한다. `scripts/test-enemy-runtime.cjs`는 실제 피해 출처, 잔불 타이밍, 치유 적용, 분열 세대, 계약 보상을 고정한다.

이 단위 테스트는 체감 난이도나 재미를 증명하지 않는다. 도입 뒤에는 기물별 생존 웨이브, 특성 적의 실제 등장 수, 수호 때문에 막힌 보조 처치 수, 잔불 사망 비율, 분열로 인한 적 누적을 플레이 로그 또는 반복 플레이로 확인해야 한다.
