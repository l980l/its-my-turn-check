# 2인 코옵 차례제 전환 평가 · v0.17.0 · 2026-10-27

## 판단 목표

동시 선택(v0.16.4)을 차례제(v0.17.0)로 바꿨을 때 생존이 크게 달라지는지 확인한다. 바뀐 규칙은 다음과 같다. 선공이 웨이브마다 번갈아 바뀐다. 처치로 턴이 이어지면 연쇄가 끝날 때까지 계속 움직인다. 뒤에 움직이는 플레이어는 앞 플레이어의 결과를 보고 고른다.

## 방법

[v0.16.4 평가](coop-v0164-report.md)와 같은 시뮬레이터, 같은 시드 48개, 같은 정책, 같은 시간 가정(웨이브당 3.34초)을 사용했다. 원시 데이터와 런타임 해시는 `coop-v0170-raw.json`에 있다.

## 해석

- 차례제 전환이 생존을 크게 바꿨다는 증거는 없다. 밸런스를 다시 조정할 필요는 없다.
- AI는 동료가 움직인 결과를 따로 활용하지 않는다. 그래서 이 결과는 "규칙만 바꿨을 때"의 차이다. 사람은 동료의 수를 보고 협력할 수 있으므로 실제 플레이에서는 차이가 더 클 수 있다. 이것은 측정하지 않았다.
- 보스 심판 사망이 9건에서 14건으로 늘었다. 더 오래 살아남아 보스를 더 많이 만난 영향으로 보이지만 확인하지 않았다.

## 한계

- 사람의 기다림, 체감 속도, 협력 의사결정은 측정하지 않았다.
- 시간 가정은 사람이 한 수에 약 1초 고민한다는 값이다. 동시 선택은 항상 1.8초를 모두 기다렸으므로, 실제로 웨이브가 빨라지는지 느려지는지는 플레이 속도에 달려 있다.
