# 4티어 특성 융합 · v0.12.1

## 플레이 규칙

- 1티어 10종, 2·3·4티어 각각 6종. 같은 직전 티어 특성 2개를 정해진 조합식으로 합친다.
- 장착 6칸, 효과가 적용되지 않는 재료 가방 8칸. 중복 재료를 보유할 수 있지만 효과는 중첩되지 않는다.
- 7레벨부터 레벨업 선택지 묶음에 35% 확률로 2티어가 등장한다. 21레벨부터 50%, 41레벨부터 65%로 올라간다. 3·4티어는 조합 전용이다.
- 7레벨부터 같은 보상 티어 안에서 현재 보유 재료와 조합할 수 있는 후보가 있으면 세 선택지에 최소 하나 포함한다. 효과 없는 재료 가방도 확인한다. 실제 융합에는 여전히 도구가 필요하다.
- 보스는 융합 도구를 남긴다. 플레이어와 겹치면 인접 빈칸을 찾아 놓는다. 일반 아이템과 독립적이며 여러 개 보관되고 자연 소멸하지 않는다.
- 가장 가까운 도구가 화면 밖이면 은색 방향 아이콘과 맨해튼 거리(칸)를 표시한다. 적 표시 3개 제한과 별도다.
- 획득 후 조합 화면에서 게임의 턴 진행을 멈춘다. 한 도구로 가능한 조합을 연속 실행한다. 실제 조합 없이 닫으면 도구가 남으며, 조합을 했다면 닫을 때 소모한다.
- 조합 화면에서 장착 특성 → 가방 특성을 눌러 교체할 수 있다. 교체만 하면 도구를 소모하지 않는다.
- 도구 획득과 조합은 플레이어 턴을 유지한다. 레벨업이 함께 발생하면 보상 선택 후 조합 화면을 연다.
- 상위 특성은 재료 효과를 자동 계승하지 않는다. 개별 공격 형태와 대상 수, 이동 거리·CHAIN 조건, 적 턴 기준 재사용 시간으로 설계한다. 상세 수치와 설명은 `traits.js`의 동일 규칙 데이터에서 생성한다.
- 1티어 공격은 직접 처치 후 최대 1기의 일반 적에게 1피해를 준다. 빈칸 착지, 단순 내구도 타격과 보조 공격으로는 특성 공격을 재발동하지 않는다.
- 보조 공격은 최대 3칸 이내이며 벽을 통과하지 않는다. 나이트 위치 공격은 나이트처럼 벽을 뛰어넘는다. 보스는 특성 보조 타격 대상에서 제외하며 직접 공격해야 한다.
- CHAIN SPARK는 직접 처치 4회마다 XP +1이다. 내구도만 깎아 XP를 반복 획득할 수 없다.
- 추가 이동은 직접 처치로 준비하며, 특성 전체가 하나의 적 턴 기준 재사용 시간을 공유한다. 여러 탈출 특성을 장착해도 같은 턴에 추가 이동을 반복하지 못한다.
- 개발자 모드에서 모든 티어 특성과 융합 도구를 직접 생성할 수 있다.

## 밸런스 평가 프로필

플레이 루프는 이동 → 타격 연쇄 → 적 턴 → 보상 → 보스 도구 회수 → 조합이다. 사용자의 목표 변경에 따라 약 50분의 장기 플레이에서 전설 6칸 완성을 목표로 삼는다. 플레이어가 턴 속도를 결정하므로 분 단위 도달률은 아직 실제 플레이로 검증하지 않았다.

검증할 가설과 조치:

1. 슬롯이 성장 경로를 막지 않는다. 실제 런타임에서 기존 전설을 유지하며 전설 6종을 순서대로 만든다. 실패하면 가방 용량/조합 접근을 수정한다.
2. 조합 재료를 복제하거나 잘못 소모하지 않는다. 모든 조합식에 대해 소모·결과·원본 불변·누락 재료를 검증한다. 실패하면 규칙 엔진을 수정한다.
3. 도구가 일반 아이템의 생성을 막거나 턴을 넘기지 않는다. 드랍·16턴 생존·획득·레벨업과 동시 획득·닫기를 게임 런타임에서 검증한다.
4. 기본 특성보다 상위 특성이 넓은 패턴을 제공하되 발동 조건과 재사용 시간이 있어야 한다. 이전 버전과 같은 보드에서 피해와 처치·XP·턴 유지를 비교한다. 실제 생존 난도와 재미는 플레이테스트가 필요하다.

실행:

```sh
node scripts/test-traits.cjs
node scripts/test-trait-combat.cjs
node scripts/test-fusion-runtime.cjs
node scripts/simulate-trait-balance.cjs
npm run prepare:web
```

관측 단위는 각 조합식과 고정 시드 `20261015`의 런타임 시나리오다. 조합식 검사는 모든 18개 조합식을 대상으로 하고, 6종 전설 도달 검사는 사전에 정한 재료를 공급하는 단일 경로다. 무작위 보상에서의 평균 도달 시간이나 실제 유저의 생존율을 의미하지 않는다. 테스트는 DOM/Canvas 대역을 사용하므로 실제 기기의 시각 배치·터치감·성능은 별도 확인 대상이다.

다음 튜닝은 실제 플레이에서 5·10·15분의 티어 분포, 도구 회수 횟수, 남은 가방 재료와 사망 웨이브를 기록한 뒤 결정한다. 출시 중인 랭킹의 점수 경제는 변경된 빌드와 별도로 비교해야 한다.

## v0.12.0 재설계와 시뮬레이션

실행 기록과 원시 데이터는 `docs/balance/trait-balance-report-v0.12.0.md` 및 같은 폴더의 JSON을 참조한다. 이전 버전을 보존해 같은 입력으로 비교했다. 실제 게임 로직의 전투 시나리오 1,024쌍에서 1티어 단독 보조 처치는 이동당 평균 1.263기에서 0.250기로 감소했다. 처치 없는 내구도 타격의 보너스 XP 위반은 이전 11건에서 현재 0건이다.

성장 시간은 실제 플레이 측정이 아니다. 분당 특성 보상 1.6회, 초기 6회 이후 보상 약 4회마다 도구 1개, 조합 가능성을 우선하는 단순 선택 정책으로 서로 다른 전설 6개 장착까지 계산했다. 64개 고정 시드 중 160회 보상(가정상 100분) 안에 완성한 경우는 28개였다. 완성한 표본만의 중앙값은 보상 114회(71.25분), 가장 빠른 표본은 66회(41.25분)였다. 나머지 36개는 상한에 도달한 미완성 표본이며, 이것이 최적 전략으로도 불가능하다는 뜻은 아니다. 레벨별 XP 요구량 증가, 실제 보스 회수 시간, 사망 및 조작 시간도 이 시간 환산에는 반영하지 않았다.

따라서 15분에 전설 6개라는 목표는 현재 수급 모델에서 충족되지 않는다. 공격 효과를 더 강하게 만들기보다 보상 빈도, 재료 선택과 조합 접근성을 별도로 조절할 근거로 사용한다.

## v0.12.1 성장 수급 조정

사용자가 최종 빌드 완성 목표를 약 50분으로 변경했다. 전투 규칙과 XP 요구량은 유지하고, 재료 보정과 후반 2티어 확률만 조정했다. 같은 분당 보상 1.6회 가정에서 전체 64개 표본의 중앙 도달 시간은 조정용 시드 51.25분, 별도 검증 시드 56.25분이었다. 100분 환산 상한 내 완성은 두 표본에서 각각 57/64였으며, 미완성 7개씩도 결과에 포함했다. 별도 검증 표본의 50분 이내 완성은 22/64로, 50분을 모든 판의 보장 시간으로 해석할 수 없다.

이 수치는 고정된 보상 속도와 단순한 재료 선택·조합 정책의 환산 결과다. 보상 획득이 느려지거나 사망하면 실제 시간과 완성률도 달라진다. 상세 결과는 `docs/balance/trait-balance-report-v0.12.1.md`와 원시 JSON을 참조한다.
