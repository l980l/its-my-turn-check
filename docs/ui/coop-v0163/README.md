# 코옵 팀원 표시·사망 UI·10수 복기 확인

## 변경

- 화면 안 동료: 흰색 기물, 흰색 블룸, P1/P2 이름표. 화면 밖 동료: P1/P2 문자, 흰색 원형 테두리와 블룸, 방향 삼각형.
- 사망 안내·팀 결과: 1인 모드의 고운바탕, 중앙 그라데이션 패널, 어두운 반투명 배경, 청록 주 버튼과 차분한 보조 버튼을 따른다. 복기는 전체 보드와 하단 분홍 제어 버튼을 사용한다.
- 코옵은 최근 10회 행동과 그 직전 장면(최대 11개), 1인 모드는 기존 5수 기록을 유지한다.

## 실행과 증거

`node scripts/test-coop-death-browser.mjs`는 로컬 서버 8000과 별도 headless Chrome CDP 9225에서 실행한다. 320×568, 390×844, 844×390, 1440×900 CSS px에 동일한 결정적 보드 상태를 주입하고 실제 포인터로 사망 안내·복기·결과 버튼을 조작한다. 별도로 살아 있는 게임 진행을 확인하는 단계 입력은 프로그램 방식이다. 실제 온라인 부하나 사람의 사용성 평가가 아니다.

실행 당시 실제/요청 크기, 컨트롤 중심 히트 검사, 텍스트 넘침, 폰트 크기, 소스 해시는 [원시 결과](coop-death-ui-results.json)에 보존한다. [평가 결과](coop-death-ui-evaluation.json)는 `eval-ui/scripts/evaluate_ui.py`의 프로젝트 임계값(텍스트 14 CSS px 권고, 버튼 24 CSS px, 넘침/화면 이탈 1px 허용)으로 생성했다. 평가기 자체의 7개 단위 테스트도 통과했다.

12개 캡처에서 해상도 불일치·텍스트 넘침·활성 컨트롤 화면 이탈·중앙 히트 실패·작은 타깃·컨트롤 겹침은 검출되지 않았다. 낮은 가로 화면에서 처음 검출된 결과 버튼 잘림은 패널 간격을 줄인 뒤 같은 조건으로 재검증했다. 고운바탕의 작은 보조 문구/복기 제어에는 11~13px 권고 경고가 남는다. 배경이 반투명/게임 장면이므로 최종 픽셀 대비는 미측정으로 남겼다. 접근성 인증이나 사용자 만족도 개선을 뜻하지 않는다.

실제 iframe Canvas 호출을 관찰해 화면 안 P2 이름표에 흰색 shadow/30px blur, 화면 밖 동료에 흰색 shadow와 반지름 13px 원 테두리가 적용됨을 확인했다. 블룸의 선호도나 iOS 기기 성능을 수치로 평가하지는 않았다.
