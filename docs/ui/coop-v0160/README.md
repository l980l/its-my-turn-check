# 코옵 공유 엔진 UI 확인

`scripts/test-coop-dev-browser.mjs`로 실제 로컬 Chrome 페이지를 포인터 조작했다. 실제 뷰포트와 요청 뷰포트의 일치, 게임 컨테이너 가로 넘침 없음, 렌더링된 버튼·텍스트 넘침 없음, 개발 버튼의 24 CSS px 이상 히트 영역, 진행 바 감소/일시정지, 재시작·배속·기물 변경·양쪽 AUTO·퇴장을 확인했다. 임계값은 프로젝트의 기계적 검사 기준이며 가독성·접근성 인증이나 사용자 만족도 지표가 아니다.

5개 조건: 320×568, 390×844, 844×390, 768×1024, 1440×900 CSS px. 이 조건들에서 런타임 예외는 수집되지 않았다. 상세 수치·실행 시각·측정 소스 해시는 [원시 JSON](coop-dev-browser-results.json)에 보존했다.

대표 실제 캡처: [320](coop-dev-320.png), [390](coop-dev-390.png), [1440](coop-dev-1440.png). 모바일/PC의 기존 보드·SVG 기물과 보라색 동료 표시를 육안으로 확인했다. 작은 DEV 화면은 두 시점을 동시에 표시하기 때문에 HUD가 작다. 일반 방에서는 본인 시점 하나만 표시한다. 개발 도구는 내부 스크롤로 나머지 버튼에 접근한다.

미검증: 실제 터치 기기, iOS 성능, 색각/언어별 이해도, 사람의 과업 수행 시간. 배경 이미지 위 텍스트의 최종 픽셀 대비를 측정하지 않았으므로 대비 통과로 해석하면 안 된다.
