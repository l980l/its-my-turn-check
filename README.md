# It’s My Turn… Check!

> One move. They advance. Check the board.

> **OpenAI Game Builders Seoul 출품작** — 이 게임으로 본선에 진출해 발표를 진행했습니다.

It’s My Turn… Check!는 다가오는 적 기물을 돌파하는 턴 기반 체스 생존 게임입니다. 판을 시작할 때 기물을 고르고, 적을 처치하면 추가 이동을 얻으며, 특성을 모으고 강화해 자신만의 기물을 만듭니다.

Play: https://l980l.github.io/its-my-turn-check/

## CO-OP ALPHA

`CO-OP ALPHA`는 2인이 같은 보드에서 차례대로 움직이는 무료 실험 모드입니다. 각자 자기 차례에 시간 제한 없이 이동을 고르고, 선공은 웨이브마다 번갈아 맡습니다. 연결이 끊긴 동료의 차례는 AUTO가 대신 둡니다. 온라인 방에서는 우측 상단에 동료와의 왕복 지연(ping)이나 연결 끊김이 표시됩니다. 이미 1초마다 주고받는 연결 확인 신호에 시각을 실어 재므로 메시지 수는 늘지 않습니다. 한 사람이 보상을 고르는 동안 동료도 같은 카드를 보고, 카드를 눌러 추천할 수 있습니다. 보드에서 내 말은 흰색, 동료 말은 흰색에 초록 테두리로 그립니다. 방장이 판정을 맡고 Supabase Realtime Broadcast는 방 연결과 입력 전달에만 사용합니다. 따라서 별도의 상시 게임 서버 비용 없이 PC와 Android WebView 사이의 크로스플레이를 시험할 수 있습니다.

현재는 비공개 방 코드, 방 안 시작 기물 선택(두 사람이 각자 고르고 둘 다 준비하면 시작), 번갈아 차례, 팀 공유 레벨·특성, 2인 전용 특성 9종(연결선·공명 파동·협공 일격·집결·합류·핀·수호·캐슬링·릴레이)과 그 숙련·조합 5종, 레벨업 보상으로 동료 부활까지 포함합니다. 팀 점수는 1인과 따로 2인 랭킹에 기록합니다.

## 플레이 방법

1. PLAY를 누르면 기물을 고릅니다. 고른 기물로 끝까지 싸웁니다.
2. 적 기물이 한 번 움직인 뒤 빛나는 이동 칸이 열립니다.
3. 한 칸을 터치하거나 클릭해 체스 규칙에 따라 이동합니다.
4. 적을 밟아 잡으면 추가 이동을 얻습니다. 연속 경로는 무지개색 선으로 표시됩니다.
5. 레벨업마다 무작위 특성을 골라 강화하세요.
6. 적 기물이 내 칸에 도달하면 체크메이트입니다. 보스의 예고 공격과 잔불 폭발에 맞아도 끝납니다.
7. 체크메이트 뒤에는 마지막 5수를 되감아 어떻게 잡혔는지 다시 볼 수 있습니다. 2인에서는 각자 사망 직전 10수를 볼 수 있습니다.

메인 화면의 `HOW TO PLAY`에서 기물, 아이템, 지형, 보스를 그림과 함께 설명합니다.

게임 중 마우스를 적 기물, 보스, 아이템, 잔불, 지형, 화면 밖 적 아이콘에 올리면 설명이 나옵니다. 적은 내구도·이동 방식·특성과 수호받는 중인지, 보스는 공격 패턴과 지금 상태를 보여 줍니다. 특성이 발동할 때 특성 칸의 이펙트는 체인이 높을수록 커지고 화려해집니다.

오른쪽 아래 ⚙ 게임 설정에서 BGM·SFX 음량, 화면 밖 적 아이콘(OFFSCREEN ICONS), 적 이동 경로 점선(ENEMY PATHS), 글씨와 패널 크기(UI SIZE)를 바꿀 수 있습니다. 경로 점선을 꺼도 사망 후 되감기에는 표시됩니다. UI SIZE의 AUTO는 창이 1440×900보다 크면 글씨와 패널을 최대 150%까지 키웁니다(QHD 모니터에서 약 145%). 100%·125%·150%로 직접 고를 수도 있고, 2인 화면에도 같은 설정이 적용됩니다.

약한 기물일수록 최종 점수에 배율이 붙습니다. 퀸 ×1.0, 룩·비숍·나이트 ×1.5, 킹 ×2.0입니다. 비숍은 대각선 외에 위로 한 칸 움직일 수 있습니다. 2인 모드도 방에서 각자 시작 기물을 고르고, 승급과 기물 변경 없이 끝까지 갑니다. 2인 팀 점수에는 두 기물 배율의 평균을 곱합니다(예: 퀸+킹 ×1.5). 폰은 8방향 한 칸을 움직이며, 적 폰도 같은 규칙을 사용합니다.

## 특성 획득과 강화

특성은 독립적인 효과 13종이며, 최대 6개를 획득합니다. 기존 28종에서 진화 전·후 효과가 중복되는 선택지를 통합하고, 기본 10종에 고리·부채꼴·복합 나이트 패턴 3종을 남겼습니다. 예전 상위 티어 효과가 별도 상위 등급으로 등장하지 않습니다. 빈 슬롯이 있을 때는 미보유 특성 3개 중 하나를 선택합니다. 6칸을 모두 채운 뒤에는 보유 특성 중 강화 가능한 최대 3개가 나오며, 하나를 골라 최대 Lv. 5까지 강화합니다. 공격 범위와 대상 수를 무작정 함께 늘리는 대신 특성별 강화 방향을 제한합니다. 보조 공격은 직접 처치 후 일반 적에게만 적용되고, 적의 내구도만 깎아서는 보너스 XP를 얻지 못합니다.

리롤은 한 게임에 총 2회이며, 특성 획득과 강화 선택창에서 공용으로 사용합니다. 다른 후보가 없으면 리롤은 비활성화되며 횟수를 소모하지 않습니다. 돋보기에서 현재 효과와 강화 후 효과를 비교할 수 있고, 상단 슬롯을 누르면 현재 레벨과 효과를 확인할 수 있습니다. 도감에서는 Lv. 1~5의 효과를 미리 살펴볼 수 있습니다.

융합 도구·재료 가방·조합식은 제거했습니다. 보스의 점수와 경험치 보상은 유지합니다. 모든 특성이 Lv. 5가 된 이후에는 레벨업으로 점수 1,000을 받습니다. 시작 기물을 고르는 v0.20.0부터는 첫 랜덤 승급과 5레벨마다의 "말 바꾸기" 갈림길이 없습니다. 레벨업은 언제나 특성 보상입니다.

숨겨진 성장도 추가했습니다. 특정 특성을 함께 보유하면 5종의 시너지 중 해당 효과가 자동으로 발동합니다. 각 특성은 자신이 실제로 기여한 처치로 별도 경험치를 쌓으며, **Lv. 5와 특성 경험치 조건을 모두 채우는 즉시 달인으로 진화**합니다. 조건을 채우는 순서는 상관없고, 한 판이 끝나면 초기화됩니다. 발견한 효과는 알림과 슬롯 표시로 확인할 수 있습니다. 달인 공격도 보스의 공격 가능 상태와 한 번에 내구도 1만 감소하는 규칙은 유지합니다.

달인 3개는 획득 제한이 아니라 약 50분 플레이를 가정한 조정 목표입니다. 로컬 성장 모델에서는 보통 처치 속도와 4개 빌드군을 동일 비중으로 섞었을 때 50분 시점 중앙값이 3개였습니다. 처치 속도·기여도·레벨업 일정을 가정한 결과이므로 실제 플레이 시간이나 생존 난이도를 보장하지는 않습니다. 입력과 한계는 `docs/balance/hidden-growth-profile.md`, 결과는 `docs/balance/hidden-growth-report.md`에 기록했습니다.

규칙 검증과 레벨별 효과·성장 횟수 비교는 다음 명령으로 실행합니다. 기존 융합 방식의 약 50분 목표는 새 방식에 적용되지 않으며, 새 구조의 실제 완성 시간과 재미는 플레이 검증이 필요합니다. 이전 융합 밸런스 자료는 `docs/balance`의 과거 기록으로 남겨뒀습니다.

```sh
npm run test:traits
npm run balance:traits
npm run balance:hidden
```

2인 모드는 다음 명령으로 검증합니다.

```sh
npm run test:coop-ui
npm run test:coop-auto
npm run test:coop-session
npm run balance:coop
```

화면 동작은 `scripts/test-*-browser.mjs`로 확인합니다. 정적 서버와 CDP 포트 9225의 headless Chrome을 띄운 뒤 `node scripts/test-coop-dev-browser.mjs http://localhost:8000`처럼 실행합니다.

- 플레이어 레벨이 오를수록 나이트·비숍·룩·킹·퀸 적이 섞여 등장합니다.
- 내 이동이 끝나면 짧은 딜레이 뒤 적 기물이 동시에 움직입니다.

## 보스

30웨이브마다 보스가 나옵니다. 순서는 IRON ROOK → BLOOD QUEEN → VOID BISHOP → CHECKMATE BISHOP → CROWN QUEEN이며, 이후 반복합니다. 보스는 공격 가능 상태일 때만 피해를 받고, 한 번에 내구도가 1씩 줄어듭니다.

| 보스 | 특징 |
| --- | --- |
| IRON ROOK | 가로·세로 관통 공격을 예고합니다. |
| BLOOD QUEEN | 봉인 상태로 나옵니다. 일반 적 4기를 처치하면 봉인이 풀립니다. |
| VOID BISHOP | 대각선 관통 공격을 예고합니다. |
| CHECKMATE BISHOP | SAFE 구역을 지정합니다. 그 칸에 도달해야 살아남습니다. |
| CROWN QUEEN | 8방향 관통 공격을 예고합니다. |

## 아이템과 지형

적이 등장할 때 일정 확률로 보드에 아이템이 놓입니다. 그 칸으로 이동하면 얻습니다.

| 아이템 | 효과 |
| --- | --- |
| KING'S AEGIS | 다음 적 턴 2회 동안 무적 |
| LONG STRIDE RUNE | 다음 3회 이동 사거리 +2 |
| SILVER NECKLACE | 공격 없이 이동해도 2회까지 턴 유지 |
| JUDGEMENT | 보드 위 모든 적에게 1 피해 |
| TREASURE CHEST | 현재 웨이브 × 100점 |

지형은 웨이브가 지날수록 늘어납니다. 벽은 12웨이브, 증폭 지대는 24웨이브, 감쇠 지대는 42웨이브, 웜홀은 60웨이브부터 나옵니다.

| 지형 | 효과 |
| --- | --- |
| 벽 | 지나갈 수 없고, 벽 너머로도 이동할 수 없습니다. |
| 증폭 지대 | 여기서 출발하면 사거리 +1 |
| 감쇠 지대 | 여기서 출발하면 사거리 −1 |
| 웜홀 | 들어가면 같은 색 웜홀로 나옵니다. |

## 적 특성

기물 색은 남은 내구도를 나타내며, 특성은 기물 둘레의 큰 배지로 구분합니다. 복수 특성은 배지를 겹치지 않게 각각 표시하며, 배지를 누르면 이동하지 않고 해당 적의 모든 특성 설명을 확인합니다. 화면 밖 적 표시와 사망 직전 장면에도 특성 배지가 나타납니다.

| 특성 | 배지 | 효과 |
| --- | --- | --- |
| 수호 | 청록 방패 | 인접 8칸의 일반 적을 특성·시너지 공격으로부터 보호합니다. 직접 공격과 아이템은 막지 않으며, 자신·다른 수호자·보스는 보호하지 않습니다. |
| 잔불 | 주황 불꽃 | 처치된 한 칸이 다음 적 턴에 폭발합니다. 연속 행동 중에는 폭발하지 않으며 무적 효과로 막을 수 있습니다. |
| 치유 | 초록 십자 | 적 이동 후 주변 2칸의 다른 일반 적 하나를 내구도 1만큼 회복합니다. 같은 적에게 여러 치유가 중첩되지 않습니다. |
| 분열 | 보라 가지 | 처치 시 빈 인접 칸에 내구도 1의 폰 최대 2기가 생성됩니다. 계보당 2단계까지만 분열하며, 마지막 세대에는 배지가 없습니다. |

새 일반 적의 특성 확률은 실제 플레이 시간에 따라 연속적으로 증가합니다. 첫 1분은 0%, 2분 6%, 5분 10%, 10분 16%, 20분 28%, 30분부터 최대 40%입니다. 첫 3턴의 안전 구간도 유지합니다. 플레이어·적 턴의 실제 경과 시간만 누적하며, 선택창·메인 화면·사망 화면·백그라운드 시간은 제외합니다. 개발자 배속과는 별개입니다.

특성 적으로 결정되면 보유 개수를 한 번에 추첨합니다. 아래는 **특성 적 내부의 비율**이며, 기준점 사이에서는 선형으로 변화합니다. 30분 전에는 모두 1특성입니다.

| 플레이 시간 | 1특성 | 2특성 | 3특성 | 4특성 |
| --- | ---: | ---: | ---: | ---: |
| 30분 | 95% | 5% | 0% | 0% |
| 40분 | 80% | 20% | 0% | 0% |
| 45분 | 65% | 30% | 5% | 0% |
| 60분 | 30% | 40% | 25% | 5% |
| 75분 이후 | 15% | 40% | 30% | 15% |

선택한 개수만큼 서로 다른 특성을 부여합니다. 예를 들어 40~45분 사이에는 3특성이 0→5%로, 45~60분 사이에는 4특성이 0→5%로 서서히 섞입니다. 분열로 생성된 폰은 남은 분열 단계만 물려받고 수호·잔불·치유는 물려받지 않습니다.

위험한 계약은 10턴간 등장 확률을 정확히 2배(최대 80%)로 올리며, 보유 개수 비율과 내구도는 변경하지 않습니다. 계약 기간에 생성된 적의 XP ×2·점수 ×1.5 보상은 유지합니다. 기존 계약 마름모는 제거했습니다. 분열로 생성된 폰은 부모의 계약 보상 여부를 물려받습니다.

개발자 모드의 `특성 적` 버튼으로 단일·복합 특성 적을 소환하고, `+5분` 버튼으로 시간별 성장을 빠르게 검사할 수 있습니다. `npm run test:enemies`로 규칙·전투 연동·배지 렌더 경로를 검증합니다. 초기 확률과 밸런스 검증 한계는 `docs/balance/enemy-traits-profile.md`에 기록했습니다.

## 개발자 모드

시작 화면의 `DEV`·`PRE` 스위치는 평소에 숨겨져 있습니다. 왼쪽 위 `BUILD` 표시를 3초 안에 다섯 번 누르면 나타나고, 개발자 비밀번호를 통과한 세션에서는 처음부터 보입니다. `DEV`를 켜고 게임을 시작하면 테스트 도구는 숨겨진 채로 시작합니다. 오른쪽 아래 ⚙를 1초 안에 다섯 번 누르면(또는 `D` 키) 나타나고, 같은 방법으로 다시 숨깁니다.

| 기능 | 버튼 / 키 |
| ---------------------- | -------------- |
| XP 즉시 획득 | `[1] +XP` |
| 인접한 폰 생성 | `[2] +PAWN` |
| 즉시 적 박자 실행 | `[3] BEAT` |
| 게임 속도 ×1 → ×2 → ×4 → ×8 → ×16 순환 | `[4] SPEED ×1` |
| 기물 직접 변경 | `[5] PIECE` |
| 특성 직접 추가 | `[6] TRAIT` |
| 보스 골라서 소환 | `[7] BOSS` |
| 자동 플레이 켜기 / 끄기 | `[8] AUTO` |
| 보유 특성 달인 강화 테스트 | `[9] MASTER` |
| 특성 적 소환 | `특성 적` |
| 플레이 시간 5분 앞당기기 | `+5분` |

테스트 도구가 숨겨져 있어도 숫자 키 단축키는 그대로 작동합니다.

2인 온라인 방의 `AUTO`(내 말 자동 플레이) 버튼도 개발자 비밀번호를 통과한 세션에서만 쓸 수 있습니다. 게임 중 상단 `CO-OP ALPHA` 글자(좁은 휴대폰에서는 연결 배지)를 1초 안에 다섯 번 누르면 나타나고, 다시 다섯 번 누르면 숨겨집니다. 로비의 `DEV` 로컬 테스트 화면은 지금처럼 도구가 바로 보입니다.

## 랭킹 탭

1인 랭킹은 `종합`, 시작 기물별(퀸·룩·비숍·나이트·킹), `레거시` 탭으로 나뉩니다. 종합과 기물별 탭에는 시작 기물 선택과 점수 배율이 들어간 v0.20.0(2026-11-11 15:48:55 UTC) 이후 기록만 나옵니다. 그 전 기록은 레거시 탭에 남습니다. 결과 화면의 TOP 10 판정과 순위도 종합 기준으로 계산합니다. 2인 랭킹은 같은 탭 줄의 마지막 `2인` 탭입니다.

랭킹 창은 탭이나 페이지를 바꿔도 크기가 바뀌지 않습니다. 한 페이지는 화면 높이가 800px 이상이면 10개, 그보다 낮으면 5개입니다. 소감은 한 줄로 잘리고, 전문은 마우스를 올리면 보입니다.

## 랭킹 보안

랭킹 테이블은 공개 읽기만 허용합니다. 점수 기록은 `leaderboard` Edge Function이 발급한 실행 토큰과 서버 기준 경과 시간을 검증한 뒤에만 저장됩니다. 따라서 공개 API로 테이블에 직접 점수를 POST하는 방식은 차단됩니다.

Supabase 구성은 `supabase/migrations/`와 `supabase/functions/leaderboard/`에 있습니다. 배포 환경에는 `RUN_TOKEN_SECRET`이 필요하며, 이 값은 저장소에 포함하지 않습니다.
