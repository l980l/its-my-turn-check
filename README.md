# It’s My Turn… Check!

> One move. They advance. Check the board.

> **OpenAI Game Builders Seoul 출품작** — 이 게임으로 본선에 진출해 발표를 진행했습니다.

It’s My Turn… Check!는 다가오는 적 기물을 돌파하는 턴 기반 체스 생존 게임입니다. 적을 처치하면 추가 이동을 얻고, 랜덤 승진과 특성 강화로 자신만의 기물을 만듭니다.

Play: https://l980l.github.io/its-my-turn-check/

## CO-OP ALPHA

`CO-OP ALPHA`는 2인이 같은 보드에서 1.8초 안에 이동을 선택하고, 두 수를 함께 판정하는 무료 실험 모드입니다. 방장이 판정을 맡고 Supabase Realtime Broadcast는 방 연결과 입력 전달에만 사용합니다. 따라서 별도의 상시 게임 서버 비용 없이 PC와 Android WebView 사이의 크로스플레이를 시험할 수 있습니다.

현재는 비공개 방 코드, 2인 동시 선택, 동시 적 이동, 나이트/비숍 역할 분담, 기본 처치 보너스까지 포함합니다. 방장 권위 방식이므로 랭킹·경쟁전에는 사용하지 않습니다.

## 플레이 방법

1. 적 기물이 한 번 움직인 뒤 빛나는 이동 칸이 열립니다.
2. 한 칸을 터치하거나 클릭해 체스 규칙에 따라 이동합니다.
3. 적을 밟아 잡으면 추가 이동을 얻습니다. 연속 경로는 무지개색 선으로 표시됩니다.
4. 첫 레벨업에서 무작위 기물로 승진하고, 이후에는 무작위 특성을 골라 강화하세요.
5. 매 5레벨에는 기물 변경 또는 특성 뽑기 중 하나를 선택할 수 있습니다.
6. 적 기물이 내 칸에 도달하면 체크메이트입니다.

시작 기물인 폰은 예외적으로 8방향 한 칸 이동할 수 있습니다. 적 폰도 같은 규칙을 사용합니다.

## 특성 획득과 강화

특성은 독립적인 효과 13종이며, 최대 6개를 획득합니다. 기존 28종에서 진화 전·후 효과가 중복되는 선택지를 통합하고, 기본 10종에 고리·부채꼴·복합 나이트 패턴 3종을 남겼습니다. 예전 상위 티어 효과가 별도 상위 등급으로 등장하지 않습니다. 빈 슬롯이 있을 때는 미보유 특성 3개 중 하나를 선택합니다. 6칸을 모두 채운 뒤에는 보유 특성 중 강화 가능한 최대 3개가 나오며, 하나를 골라 최대 Lv. 5까지 강화합니다. 공격 범위와 대상 수를 무작정 함께 늘리는 대신 특성별 강화 방향을 제한합니다. 보조 공격은 직접 처치 후 일반 적에게만 적용되고, 적의 내구도만 깎아서는 보너스 XP를 얻지 못합니다.

리롤은 한 게임에 총 2회이며, 특성 획득과 강화 선택창에서 공용으로 사용합니다. 다른 후보가 없으면 리롤은 비활성화되며 횟수를 소모하지 않습니다. 돋보기에서 현재 효과와 강화 후 효과를 비교할 수 있고, 상단 슬롯을 누르면 현재 레벨과 효과를 확인할 수 있습니다. 도감에서는 Lv. 1~5의 효과를 미리 살펴볼 수 있습니다.

융합 도구·재료 가방·조합식은 제거했습니다. 보스의 점수와 경험치 보상은 유지합니다. 모든 특성이 Lv. 5가 된 이후에는 레벨업으로 점수 1,000을 받습니다. 5레벨마다 기물 변경을 선택할 수 있는 기존 규칙도 유지합니다.

숨겨진 성장도 추가했습니다. 특정 특성을 함께 보유하면 5종의 시너지 중 해당 효과가 자동으로 발동합니다. 각 특성은 자신이 실제로 기여한 처치로 별도 경험치를 쌓으며, **Lv. 5와 특성 경험치 조건을 모두 채우는 즉시 달인으로 진화**합니다. 조건을 채우는 순서는 상관없고, 한 판이 끝나면 초기화됩니다. 발견한 효과는 알림과 슬롯 표시로 확인할 수 있습니다. 달인 공격도 보스의 공격 가능 상태와 한 번에 내구도 1만 감소하는 규칙은 유지합니다.

달인 3개는 획득 제한이 아니라 약 50분 플레이를 가정한 조정 목표입니다. 로컬 성장 모델에서는 보통 처치 속도와 4개 빌드군을 동일 비중으로 섞었을 때 50분 시점 중앙값이 3개였습니다. 처치 속도·기여도·레벨업 일정을 가정한 결과이므로 실제 플레이 시간이나 생존 난이도를 보장하지는 않습니다. 입력과 한계는 `docs/balance/hidden-growth-profile.md`, 결과는 `docs/balance/hidden-growth-report.md`에 기록했습니다.

규칙 검증과 레벨별 효과·성장 횟수 비교는 다음 명령으로 실행합니다. 기존 융합 방식의 약 50분 목표는 새 방식에 적용되지 않으며, 새 구조의 실제 완성 시간과 재미는 플레이 검증이 필요합니다. 이전 융합 밸런스 자료는 `docs/balance`의 과거 기록으로 남겨뒀습니다.

```sh
npm run test:traits
npm run balance:traits
npm run balance:hidden
```

## 난이도 흐름

- 시작 구간에는 폰만 등장하며, 첫 3턴은 안전 구간입니다.
- 플레이어 레벨이 오를수록 나이트·비숍·룩·킹·퀸 적이 섞여 등장합니다.
- 내 이동이 끝나면 짧은 딜레이 뒤 적 기물이 동시에 움직입니다.

## 개발자 모드

시작 화면의 `DEV MODE · TEST TOOLS`를 켜면 테스트 도구가 나타납니다.

| 기능                   | 버튼 / 키      |
| ---------------------- | -------------- |
| 즉시 승진 XP 획득      | `[1] +XP`      |
| 인접한 폰 생성         | `[2] +PAWN`    |
| 즉시 적 박자 실행      | `[3] BEAT`     |
| 게임 속도 1× / 2× 전환 | `[4] ×2 SPEED` |
| 기물 직접 변경 | `[5] PIECE` |
| 특성 직접 추가 | `[6] TRAIT` |
| 보유 특성 달인 강화 테스트 | `[9] MASTER` |

`D` 키로 개발자 도구 표시를 숨기거나 다시 열 수 있습니다.

## 랭킹 보안

랭킹 테이블은 공개 읽기만 허용합니다. 점수 기록은 `leaderboard` Edge Function이 발급한 실행 토큰과 서버 기준 경과 시간을 검증한 뒤에만 저장됩니다. 따라서 공개 API로 테이블에 직접 점수를 POST하는 방식은 차단됩니다.

Supabase 구성은 `supabase/migrations/`와 `supabase/functions/leaderboard/`에 있습니다. 배포 환경에는 `RUN_TOKEN_SECRET`이 필요하며, 이 값은 저장소에 포함하지 않습니다.
